# my-code-vault
i store all my codes here

snippet is chunk of codes store seperately to reuse in the future

## Online vault

`code_vault_online.html` is a searchable browser view of all snippets. Open it via
githack (repo must be public):

https://raw.githack.com/parepiy/my-code-vault/main/code_vault_online.html

Each snippet's popup can show an example of its output — add `outputs/<id>.csv`
(or `<id>.png`) and it appears automatically. See `outputs/README.md`.
